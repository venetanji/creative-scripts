# Provenance And Reuse Boundaries

This directory consolidates the completed production record through the
2026-10-20 local4K export. Documentation was assembled2026-10-21 from actual
source graphs, structured prompts, frame maps, selected source modules,
stage provenance, assembly maps and verification records. Old setup files
and proposed experiments were not treated as final production truth.

## What Is Banked

- Eight original-B procedural algorithm/render modules, byte-preserved and
  hashed in [source-provenance.json](workflows/source-provenance.json).
- All27 base-film structured H3 prompts, separately hashed in the same file.
- Exact27-shot source/native selection maps, seeds and audio-conditioning
  bounds, extracted into [base-film-frame-map.json](workflows/base-film-frame-map.json).
- Six small normalized executed API graphs: opening, edge-guided successor,
  selected RGB-history repair, full-shot and shorter local LTX detail, FILM.
  [graph-provenance.json](workflows/graph-provenance.json) lists original
  source hashes and every asset-name/output-prefix substitution.
- Final edit/clock/patch metadata in [final-delivery.json](workflows/final-delivery.json)
  and a read-only verification tool. This is an archival EDL/validation
  contract, not a ComfyUI graph or fully automated edit renderer.

The graph topology, links, prompts, seeds, model names and sampling settings
are retained. Public input bindings are relative portable examples; actual
input images/video/audio must be prepared and supplied separately. Do not
interpret a normalized graph's hash as the original execution graph's hash.

## What Is Not Redistributed

Music/stems/MIDI, derived feature/spectrum/event arrays, selected camera-lock
data, guide movies, generated picture banks, original videos/latents, model
weights, SDK binaries and proprietary implementation are absent. Workflow
documentation is not evidence of rights to redistribute third-party assets.
Use independently authorized inputs and comply with each dependency's terms.

Local endpoints, home paths, credentials, process/approval ledgers, raw
terminal histories and private performance/comparative evaluations are also
excluded. Existing local evidence remains local; this is a readable source
recipe archive, not a dump of the production machine.

## Reproduction Claims

These files preserve how the video was made and provide reusable graph and
frame/audio procedures. They do **not** promise bit-exact GPU replay,
complete original raw retention, a turnkey browser reconstruction, or a
completed Easel API/client integration for these experimental combinations.
Some old raw PNGs were already absent at final assembly. Retained compressed
natives, selected lossless banks, graph metadata and pixel witnesses were
used for the documented verification; that is not full raw/latent archival.

The graph foundation is
[`venetanji/creative-skills`](https://github.com/venetanji/creative-skills).
Production graphs include project-specific native combinations and live
node contracts, not a guarantee that every current public wrapper exposes
the same options. Validate model filenames and registered schemas against
your own backend. Native H3 temporal layout and LTX's `8k+1` preparation
must not be interchanged.

Source-model filename references identify artifacts, not a license to fetch
or run them. No download, install, license acceptance, backend change or GPU
submission is performed by this documentation package.

## Local Deliverables Versus The Showcase

The immutable720p master and latest4K candidate hashes are recorded in the
delivery contract. They identify local files only. The artist supplied the
[YouTube showcase](https://www.youtube.com/watch?v=2aDa_EmED8g); its oEmbed
metadata identified **Pixel Dreams** by **Giovanni Lion** at documentation
time. Neither that metadata nor a matching title proves which exact local
candidate was uploaded, or that a YouTube transcode matches the source hash.
No YouTube upload or modification was performed for this repository update.

Remaining visual defects are stated in the production/finishing notes.
A passed decoder, file hash or frame-count check does not certify seamless
motion, faithful mathematical topology, flicker-free playback or artistic
acceptance.
